pytdx 翻新后的文件结构
========================

核心修改
--------
hq.py                                    # 修改：添加 get_block_dat_ver_up()
parser/get_security_list.py             # 修改：支持新版协议（16字节名称）
parser/get_block_info.py                # 修改：添加错误处理和日志
reader/block_reader.py                  # 修改：硬化解析逻辑
util/__init__.py                        # 修改：导出编码函数

新增模块
--------
util/encoding.py                        # 新增：统一编码处理模块
  ├── decode_tdx_text()                 # 解码固定长度文本（GBK/GB18030）
  ├── decode_tdx_code()                 # 解码证券代码（UTF-8）
  ├── safe_encode_gbk()                 # 安全编码为 GBK
  └── validate_text_field()             # 验证解码后的文本
